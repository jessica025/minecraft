# 我的世界 🌍

一个运行在浏览器中的 Minecraft 风格 3D 沙盒游戏，基于 Three.js 构建，无需安装任何依赖，打开 `index.html` 即可游玩。

## 功能特性

- **程序化地形生成** — Perlin 噪声 (fBm) 生成连绵山丘与平原
- **多种生物群系** — 草地、沙漠、砾石地带、雪地高山
- **14 种方块** — 草地、泥土、石头、木头、树叶、沙子、圆石、木板、玻璃、砖块等
- **树木生成** — 地形中自动生长随机高度的树木
- **挖掘 & 放置** — 左键按住挖掘（不同方块耐久不同），右键放置
- **飞行模式** — 自由探索世界
- **动态区块加载** — 按视距动态加载/卸载区块，保持流畅帧率
- **第一人称物理** — 重力、跳跃、AABB 碰撞检测

## 快速开始

直接用浏览器打开 `index.html`：

```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

> 也可以用 VS Code Live Server 等本地服务器运行，效果相同。

## 操作说明

| 操作 | 功能 |
|------|------|
| `WASD` / 方向键 | 移动 |
| `空格` | 跳跃（飞行时上升）|
| `Shift` | 下蹲减速（飞行时下降）|
| 鼠标左键（按住）| 挖掘方块 |
| 鼠标右键 | 放置方块 |
| 滚轮 / `1`-`9` | 切换手持方块 |
| `F` | 切换飞行模式 |
| `ESC` | 暂停 / 释放鼠标 |

## 项目结构

```
minecraft/
├── index.html          # HTML 结构与脚本引入
├── css/
│   └── style.css       # 界面样式（HUD、菜单、物品栏）
└── js/
    ├── noise.js        # Perlin 噪声算法（fBm）
    ├── blocks.js       # 方块类型、颜色、挖掘时间定义
    ├── world.js        # 地形生成、树木生成、区块网格构建
    ├── game.js         # 玩家物理、碰撞、渲染循环、输入处理
    └── main.js         # 入口启动
```

## 技术栈

- [Three.js r128](https://threejs.org/) — 3D 渲染
- 原生 JavaScript (ES6+) — 无框架、无构建工具
- Pointer Lock API — 鼠标捕获
- Canvas API — 物品栏图标绘制
